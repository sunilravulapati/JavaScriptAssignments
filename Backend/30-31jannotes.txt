->whenever we are trying to read nested documents(in js it is objects)
  db.emp.findOne({"address.city":"hyd"})
->whenever we want to read something from an array
  db.emp.findOne({skills:"js"}) -> use this only for single element comparison
->db.emp.findOne({skills:["js","react"]}) -> will not work as it will assume the array and try to find it and also if the 
  order is not same then it will return null as the output
->whenever we searching for multiple then we should use $all(used for arrays mainly)(this helps even if the order is not same!)
  ex: db.emp.findOne({skills:{$all:["js","css"]}})
  $in can also be used when we are trying to compare not only for arrays
->db.emp.updateOne({eno:100},{$set:{name:"ravi kumar"}})
->db.emp.updateOne({eno:100},{$set:{"address.street":"r1"}}) -> if there is a street property then the value is changed else it will be added
->$set is used to add or update a property(top level or nested)
->to delete a property we use $unset
  db.emp.updateOne({eno:100},{$unset:{name:""}})
  db.emp.updateOne({eno:100},{$unset:{"address.pincode":""}})
->array update operators: $addToSet : adds new if not exists,$push : adds even if it exists
                          $each : add multiple ex:db.emp.updateOne({eno:100},{$push:{skills:{$each:["nodejs","java"]}}})
                          $pop : remove first or last ex: db.emp.updateOne({eno:100},{$pop:{skills:1(last)}/-1(first)}}) 
                          $pull : removes one element matched with a condition ex: db.emp.updateOne({eno:100},{$pull:{skills:"css"}})
