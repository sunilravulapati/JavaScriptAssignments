REST API - REpresentational State Transfer API
Endpoints: it is a url where your api can be accessed to perform specific operations on resources
ex: http:localhost:3000/users/123
    /* base url      *//*Endpoint*/
Endpoint rules: 1. Use nouns + http methods, not verbs
                    ex: GET /users
                2. Use plural nouns
                3. Use lowercase and  hyphens
                    ex: GET /user-profiles
