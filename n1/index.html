JavaScript Fundamentals

Core concepts including loops, operators, and data types.

Loops & Iteration

You explored different ways to iterate over data.

  • for...of: Best for iterating over arrays (values).
  • for...in: Best for iterating over object properties (keys).
// From 1.js & 2.js
let marks = [45, 67, 89];
for(let v of marks) { total += v; }

for(let key in empObj) { console.log(key); }

Mutability

Primitives: Immutable (cannot change once created).
References (Arrays/Objects): Mutable (can be modified).

Functions

Different ways to define and use functions.

3 Ways to Define

Declaration

function f1(a,b){ return a+b; }

Expression

let f2 = function(a,b){ return a+b; }

Arrow

let f3 = (a,b) => a+b;

Callback Functions

Passing a function as an argument to another function. Essential for asynchronous operations (like server fetching), though your notes focused on the syntax.

// From 4.js
function test1(a){ console.log(a()) }

test1(function(){ return 123; }) 
// Anonymous function passed as argument

Objects

Key-value pairs, methods, and the `this` keyword.

Object Operations

  • Access: Dot notation (`obj.name`) or Bracket (`obj["name"]`).
  • Dynamic: You can add/delete properties on the fly.
  • Freeze: Object.freeze(obj) stops modifications.

Destructuring & Methods

// From 2.js
let student = {
    name: "sam",
    marks: [90, 80],
    getData: function() {
        // 'this' refers to current object
        console.log(this.marks[0]); 
    }
}

// Destructuring
let {name, marks} = student;

Higher-Order Functions

The modern way to handle data without standard `for` loops.

Map (Transform)

Creates a new array by modifying every element.

// From 5.js
let salaries = [100, 200];
let up = salaries.map(s => s + 50); 
// Result: [150, 250]

Filter (Select)

Creates a new array with only elements that pass a test.

// From 7.js
let res = students.filter(s => s.age < 20);

Reduce (Aggregate)

Boils an array down to a single value (sum, max, etc).

// From 11.js
let total = cart.reduce((acc, s) => 
    acc + (s.price * s.quantity), 0
);

⚡ Function Syntax Quick Guide

Type Syntax Use Case
Declaration function sum(a,b) { ... } Code level control, hoisting.
Expression const sum = function(a,b) { ... } Application level control.
Arrow const sum = (a,b) => a+b Concise, one-liners, modern standard.

📦 Array Methods Cheat Sheet

Distinguishing between methods that change the original array (Mutable) and those that create a new one (Immutable).


Goal Method Returns Original Array?
Add to End push() New Length Modified ✏️
Remove End pop() Removed Item Modified ✏️
Transform map() New Array Unchanged 🔒
Select/Filter filter() New Array Unchanged 🔒
Calculate/Sum reduce() Single Value Unchanged 🔒
Find Item find() Item Unchanged 🔒

🔑 Object Essentials

  • Creation: let obj = { key: value }
  • Access: Dot obj.key or Bracket obj["key"]
  • Destructuring: let { name, age } = obj; — extracts properties into variables.
  • Freezing: Object.freeze(obj) — makes the object immutable (cannot change properties).
  • Traversal: Use for...in loops for objects.
